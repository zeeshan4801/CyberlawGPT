# ⚖️ CyberlawGPT

AI-powered Pakistan Cyber Law Assistant using Retrieval Augmented Generation (RAG).

## Features

✅ PECA based legal question answering  
✅ FAISS vector search  
✅ Sentence Transformer embeddings  
✅ Groq LLM integration  
✅ Adjustable response style  
✅ Technicality control  
✅ Urdu / English / Roman Urdu answers  
✅ Streamlit Cloud compatible  
✅ Google Colab compatible  


# Technology Stack

- Python
- Streamlit
- FAISS
- Sentence Transformers
- Groq API
- PyMuPDF
